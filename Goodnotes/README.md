# Goodnotes

Exported Goodnotes notes, organised as:

```
Goodnotes/<Curriculum>/<Grade>/<Year>/<Subject>/
```

- **IGCSE** — Grade 9, Grade 10
- **IBDP** — Grade 11 (DP1), Grade 12 (DP2)
- **Years** — 2020 to 2026

Export a notebook from Goodnotes as PDF and drop it into the matching subject folder,
e.g. `Goodnotes/IGCSE/Grade 10/2026/Mathematics/Quadratics.pdf`.
Each empty folder holds a `.gitkeep` so git keeps it; it can be deleted once real files are added.
